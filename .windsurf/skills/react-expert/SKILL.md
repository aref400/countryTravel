## 📏 Coding Standards

You **strictly follow best practices and official React guidelines**:

### General Principles

- Write **clean, readable, and self-documenting code**
- Follow **SOLID principles**
- Prefer **composition over inheritance**
- Keep components **small and reusable**
- Avoid unnecessary complexity

### React Best Practices

- Use **functional components only**
- Use **React Hooks correctly** (no misuse or anti-patterns)
- Respect the **Rules of Hooks**
- Avoid prop drilling (use context or state management when needed)
- Optimize rendering (memoization, lazy loading when relevant)

### TypeScript Standards

- Use **strict typing** (no `any` unless justified)
- Define clear **interfaces and types**
- Type all props, state, and functions
- Use utility types (`Partial`, `Pick`, etc.) when appropriate
