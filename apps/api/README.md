# CountryTravel — API

Backend NestJS 10 + Prisma 5 + PostgreSQL

## Setup

1. Copie `.env.example` en `.env` et remplis les variables
2. `npm install`
3. `npx prisma migrate dev`
4. `npm run start:dev`

## Docs API

Swagger disponible sur http://localhost:3000/api/docs

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
